# `patient_pattern_analysis` Directory Guide

This directory stores patient-level summaries and coactivation analyses derived from:

- `outputs/disentangleNet/v31_current_verify/window_basis_activations_all/window_basis_activations_wide.csv`

Recommended top-level entry files:

- `report_zh.md`
- `DIRECTORY_MAP_zh.md`
- `patient_profile_summary/report.md`
- `tsne/index_pages/report.md`

## Current Layout

### `patient_profile_summary/`

Patient-level aggregation outputs generated by:

- `scripts/disentangleNet/analysis/analyze_patient_activation_patterns.py`

Key files:

- `patient_activation_profiles.csv`
  - one row per patient
  - includes patient-mean basis usage / activation / coeff summaries
- `summary_by_side_label.csv`
- `summary_by_dataset.csv`
- `summary_by_dataset_and_side_label.csv`
- `patient_extreme_rankings.csv`
- `crosstab_*.csv`
  - patient pattern and dominant-basis contingency tables
- `report.md`
- `summary.json`

Default output path in script:

- `.../window_basis_activations_all/patient_pattern_analysis/patient_profile_summary/`

### `coactivation/by_<class_col>/<feature_family>/`

Class-conditional coactivation analyses generated by:

- `scripts/disentangleNet/analysis/analyze_class_coactivation_patterns.py`

Naming rule:

- `<class_col>` is the grouping label, for example:
  - `side_label_name`
  - `dataset_name`
  - `score`
  - `label_5class`
- `<feature_family>` is one of:
  - `activation`
  - `usage`

Examples:

- `coactivation/by_side_label_name/activation/`
- `coactivation/by_dataset_name/usage/`
- `coactivation/by_score/activation/`
- `coactivation/by_label_5class/usage/`

Each analysis folder contains:

- `basis_manifest.csv`
- `class_correlation_long.csv`
- `pairwise_corr_diff_tests.csv`
- `mean_<feature_family>_by_<class_col>.csv`
- `mean_<feature_family>_by_<class_col>.png`
- `correlation_heatmaps/`
- `delta_heatmaps/`
- `report.md`
- `summary.json`

Default input path in script:

- `.../patient_pattern_analysis/patient_profile_summary/patient_activation_profiles.csv`

Default output path in script:

- `.../patient_pattern_analysis/coactivation/by_<class_col>/<feature_family>/`

### `tsne/<cohort>/<basis_scope>/`

Patient-level t-SNE analyses generated by:

- `scripts/disentangleNet/analysis/analyze_patient_tsne.py`

Current families of result roots:

- `tsne/all/all_basis/`
- `tsne/all/no_side/`
- `tsne/all/side_only/`
- `tsne/imr/all_basis/`
- `tsne/imr/no_side/`
- `tsne/imr/side_only/`
- `tsne/tt/all_basis/`
- `tsne/tt/no_side/`
- `tsne/tt/side_only/`

Each result root contains:

- `usage/`
- `activation/`
- `combined/`
- `report.md`
- `summary.json`

Each feature-family folder contains:

- `tsne_2d/`
- `tsne_3d/`

Each `tsne_2d/` folder contains:

- one embedding CSV
- four class-colored plots
- one combined plot

Each `tsne_3d/` folder contains:

- one embedding CSV
- four class-colored plots
- one combined plot
- one rotating combined GIF

### `tsne/index_pages/`

Reusable overview pages generated by:

- `scripts/disentangleNet/analysis/build_tsne_index_pages.py`

Current outputs:

- `combined_2d_index.png`
- `usage_2d_index.png`
- `activation_2d_index.png`
- `report.md`
- `summary.json`

## Legacy Outputs

### `legacy_pre_naming_cleanup/`

This folder preserves older outputs created before the directory naming cleanup.

- Files here are kept for traceability.
- New runs should use the normalized paths described above.

## Regeneration Commands

Rebuild patient-level summaries:

```bash
python scripts/disentangleNet/analysis/analyze_patient_activation_patterns.py analyze
```

Rebuild coactivation analysis for one grouping:

```bash
python scripts/disentangleNet/analysis/analyze_class_coactivation_patterns.py analyze \
  --class_col side_label_name \
  --feature_family activation \
  --n_perm 4000
```

Other valid `--class_col` values currently used:

- `dataset_name`
- `score`
- `label_5class`

Build t-SNE overview pages:

```bash
python scripts/disentangleNet/analysis/build_tsne_index_pages.py build
```
