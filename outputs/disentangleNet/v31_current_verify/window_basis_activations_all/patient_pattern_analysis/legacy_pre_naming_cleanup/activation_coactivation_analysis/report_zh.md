- **b10**：在 Left 类中与 b0/b1 呈正相关（~0.545），在 Right 类中变为负相关（−0.212），在 Normal 类中相关性最弱（~−0.26）。说明 b10 是侧别语义的关键编码基。

## 关键发现总结

| 发现 | 描述 |
|------|------|
| **全局效应显著** | pseudo-F = 513.36，p = 0.00025，说明三类的基激活模式整体差异高度显著 |
| **b4/b5/b6 三联体** | 在各类中均保持强线性关系，组内相关系数接近 ±1，可能代表某种基础运动方向的相位调制 |
| **b8/b9 是侧别标记** | Left → 正相关（0.83），Normal → 负相关（−0.30），Right → 强正相关（0.73），是区分侧别最强的基对 |
| **b10 编码左右方向** | Left 中与 b0/b1 正相关，Right 中变为负相关，Normal 中几乎无关——b10 是左/右侧别方向的关键编码器 |
| **b0/b1 不变体** | 在所有类别中均保持 r = 1.000 的完全正相关，可能编码与侧别无关的通用面部运动成分 |
| **Left vs Normal 差异最大** | Δr 最大达 1.129（b8/b9），说明正常与左侧面瘫之间的共激活模式重构最为剧烈 |
