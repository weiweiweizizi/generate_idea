# 结合Blendshape标注的弱监督公共基分解

**状态**: 草稿

**日期**: 2026-03-31

---

## 1. 问题背景

### 1.1 SVD验证的结论

- ✅ 存在跨群体的公共动作基（341×341 ΔD矩阵形式）
- ✅ 基有明确语义（PC1 dominant = mouth运动）
- ✅ 无需额外信息即可通过SVD找到

### 1.2 SVD的局限

- **依赖变异性驱动**：显著运动主导特征值，隐藏运动难以捕获
- **单一动作限制**：当前视频中患者只做了一种动作，无法验证能否建模"共同但不显著"的运动
- **语义精度不足**：PC1与mouth相关，但无法精确到具体AU级别

### 1.3 核心目标

**超越SVD**：用blendshape监督引导，学习：
1. 更精确的AU级别动作基
2. 能够捕获"不显著但共同"的隐藏运动
3. 保持基的341×341形式（可解释性）

---

## 2. 方案3：神经网络端到端学基

### 2.1 核心思想

把SVD的数学操作"神经网络化"：
- **基**：可学习权重矩阵，初始化为SVD基
- **正交性**：通过损失函数软约束
- **监督信号**：blendshape重构误差

### 2.2 网络结构

```
输入: ΔD (341×341)  [一个窗口的差分距离矩阵]
  ↓
Motion Basis层
  - 可学习权重 B ∈ R^(341×341 × K)  (K个基，初始化为SVD的前K个基)
  - 输出: 激活系数 c ∈ R^K
  ↓
Blendshape Decoder
  - 全连接层: c → blendshape (52维)
  ↓
输出: blendshape_pred (52维)
```

**关键设计**：
- 基B保持341×341形式，与SVD基一致
- 正交性通过损失函数约束，而非数学正交

### 2.3 损失函数

```
L = α * ||blendshape_pred - blendshape_gt||²           # 重构误差
  + β * ||B · B.T - I||²                               # 正交性正则
  + γ * ||B - B_SVD||²                                 # 初始化正则
```

| 项 | 作用 |
|---|---|
| 重构误差 | 让基的激活系数能预测blendshape，引导语义对齐 |
| 正交性正则 | 让基保持近似正交（SVD的数学性质） |
| 初始化正则 | 保持基接近SVD初始解，避免偏离太远 |

### 2.4 训练策略

1. **阶段1**：高初始化正则 + 低正交性，让网络先用blendshape学语义
2. **阶段2**：逐渐降低初始化正则，增加正交性约束，让基趋于正交
3. **阶段3**：微调，平衡三项损失

## 3. 数据流

### 3.1 输入输出

```
输入:
  - ΔD: 341×341 差分距离矩阵
  - blendshape_gt: 52维 blendshape标签

输出:
  - blendshape_pred: 52维 重构blendshape
  - 激活系数 c: K维 基激活向量
```

### 3.2 窗口处理

- **方案1**：保持20帧窗口（与SVD一致）
- **方案2**：缩小窗口（如5帧）+ 滑动步进，捕获更多隐藏运动

> ⚠️ 窗口粒度是待解决的问题，可能影响隐藏运动的捕获

---

## 4. 优势

| 优势 | 说明 |
|---|---|
| **基的形式不变** | 始终为341×341，可直接与SVD基对比 |
| **可解释性保持** | 基可reshape成热图，激活系数可时序分析 |
| **blendshape监督** | 引导基学习精确AU语义 |
| **正交性约束** | 损失函数软约束，保持SVD特性 |
| **初始化基于SVD** | 有监督的微调，训练更稳定 |

---

## 5. 潜在挑战

| 挑战 | 可能解决方案 |
|---|---|
| blendshape监督是否足够强？ | 增加多任务学习：同时预测多帧blendshape |
| 正交性软约束可能不如SVD严格 | 调整β权重，或用硬约束（如SVD后处理） |
| 隐藏运动可能被窗口淹没 | 考虑更细粒度的滑动窗口 |
| 基可能退化成单位矩阵 | 增加谱范数正则 |
