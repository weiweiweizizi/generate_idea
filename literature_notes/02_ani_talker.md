# 文献笔记：AniTalker

> **论文**: AniTalker: Animate Vivid and Diverse Talking Faces through Identity-Decoupled Facial Motion Encoding
> **作者**: Tao Liu et al. (X-LANCE Lab, Shanghai Jiao Tong University)
> **年份**: 2024
> **arXiv**: 2405.03121
> **方向标签**: #talking-face #motion-encoding #identity-disentanglement #self-supervised

---

## 一句话核心思想

用**自监督学习**训练一个通用运动编码器，从单张静态人像+音频生成多样化、可控制的说话人脸视频，运动编码器显式解耦身份信息与运动信息。

---

## 解决的问题

- 现有方法主要关注唇同步，忽略非语言表情和头部运动
- 现有运动表示（blendshape/landmark/3DMM）是为单图设计的，近似能力有限
- 之前可学习的运动编码器只针对特定说话人，或只建模口型区域

**目标**: 学习一个**通用、细粒度**的运动表示，适用于任意角色，捕获从微表情到大幅度头部运动的全部面部动态。

---

## 方法

### 训练阶段（自监督）

```
同一视频取源帧 Is 和目标帧 It
        ↓
┌─────────────────────────────────────┐
│ 运动编码器: It → 运动特征向量         │
│ (捕获所有面部动态：口型、表情、头部)    │
├─────────────────────────────────────┤
│ 身份编码器: Is → 身份特征向量          │
│ (度量学习，最大化类间距离)              │
├─────────────────────────────────────┤
│ 互信息神经估计 (MINE)                │
│ 显式最小化运动编码中的身份信息          │
└─────────────────────────────────────┘
        ↓
   运动特征 = 纯运动，不含身份
```

### 推理阶段（扩散生成）

```
输入音频/控制信号
        ↓
   运动编码器 → 运动特征
        ↓
   扩散模型 + 方差适配器
        ↓
   多样化运动序列生成
        ↓
   运动→视频渲染 → 说话人脸
```

---

## 关键创新

1. **通用运动表示**: 捕获所有面部动态（口型+表情+头部），不局限于口型区域
2. **互信息解耦**: MINE显式最小化运动中的身份信息，确保通用性
3. **自监督学习**: 不需要标注数据
4. **扩散模型+方差适配器**: 多样化生成 + 可控性
